# ValConvex 1.2

## UI refresh

- Reworked the dark palette into a layered graphite interface with restrained violet accents.
- Added a clear active navigation indicator and subtle hover feedback.
- Standardized ttk buttons, entries, comboboxes, notebook tabs, tree headers, and selection states.
- Refined reusable stat tiles and card borders.
- Preserved the existing layout mode, interface scale, table density, and sidebar mode settings.
- Updated the application and exported-match version to 1.2.0.

This release is a visual refresh. It does not intentionally alter Riot data retrieval, match processing, match history, heatmap, profile, or export behavior.
